Este documento detalla una actividad evaluativa de la Institución Universitaria Digital de Antioquia diseñada para el curso de cálculo integral. El objetivo principal es que los estudiantes comprendan la factorización de polinomios mediante el uso pedagógico de un modelo de áreas. Para lograrlo, los alumnos deben construir físicamente fichas de cartón y, simultáneamente, desarrollar una simulación digital empleando herramientas de inteligencia artificial. El proceso exige documentar cada etapa en un cuaderno virtual, analizando tanto casos factorizables como aquellos que no permiten una solución con números enteros. Finalmente, el ejercicio busca integrar el pensamiento concreto, algebraico y tecnológico como base para futuros conceptos matemáticos de acumulación de áreas.
